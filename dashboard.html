Configuration

The house bank determines which institution's FX rate feed is used to consolidate balances held in different currencies into a single reporting currency. Switching the house bank re-prices the entire dashboard. All figures are sandbox / mock data modelled on the published API schemas of each bank's developer portal and are not connected to live accounts.

Settings persisted to localStorage. To connect live data, replace the mock loaders in BANKS.<bank>.fetchAccounts() with authenticated calls to each developer-portal sandbox.
